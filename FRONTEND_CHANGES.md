## ZKPassportNFT — On-Chain Verification

### Overview

ZKPassportNFT uses **on-chain ZK proof verification**. The proof is generated by the ZKPassport SDK in the user's browser/app and verified on-chain by the deployed `IZKPassportVerifier` contract (`0x1D000001000EFD9a6371f4d90bB8920D5431c0D8`).

**No backend required.** The contract itself calls the verifier and extracts:
- `uniqueIdentifier` (bytes32 scoped nullifier — anti-sybil)
- `personhoodVerified` (always true when minted)
- `isOver18` (cryptographically proven)
- `nationality` (ISO alpha-3 from passport/ID)

> ⚠️ **Network support**: The ZKPassport verifier is live on **Base** and **Ethereum Mainnet** only. The contract is deployed on Unichain and Optimism too — when ZKPassport adds those chains, call `setVerifier(newAddress)` as the owner to activate them.

### Step 1 — Check if user already has an NFT

```typescript
import { useReadContract, useAccount } from 'wagmi';

function useHasZKPassport() {
  const { address } = useAccount();
  const { chainId }  = useChainId();
  const network      = chainIdToNetwork(chainId);
  const nftAddress   = getAddresses(network).addresses.ZKPassportNFT;

  return useReadContract({
    address: nftAddress,
    abi:     ZKPassportNFT_ABI,
    functionName: 'hasNFTByAddress',
    args:    [address],
  });
}
```

### Step 2 — Run the ZKPassport SDK query

The query requests **all four fields** in a single proof. The `mode: "compressed-evm"` flag is **required** for on-chain verification.

```typescript
import { ZKPassport } from '@zkpassport/sdk';

const DOMAIN = 'ethcali.com';
const SCOPE  = 'ethcali-verification';

async function buildZKPassportQuery(userAddress: `0x${string}`, chain: 'base' | 'ethereum') {
  const zkPassport  = new ZKPassport(DOMAIN);

  const queryBuilder = await zkPassport.request({
    name:    'ETHcali',
    logo:    'https://ethcali.com/logo.png',
    purpose: 'Prove your identity to access ETHcali contracts',
    scope:   SCOPE,
    mode:    'compressed-evm', // required for on-chain verification
  });

  let capturedProof: any;

  const { url, onProofGenerated, onResult, onError } = queryBuilder
    .gte('age', 18)              // → isOver18 on-chain
    .disclose('nationality')     // → nationality on-chain
    .bind('user_address', userAddress)
    .bind('chain', chain)        // must match the network you're minting on
    .done();

  onProofGenerated((proof) => {
    capturedProof = proof;
  });

  onResult(async ({ verified, result }) => {
    if (!verified) {
      console.error('ZKPassport verification failed');
      return;
    }

    // Build the on-chain params
    const verifierParams = zkPassport.getSolidityVerifierParameters({
      proof:   capturedProof,
      scope:   SCOPE,
      devMode: false,
    });

    // ID card = true for ID cards / residence permits, false for passports
    const isIDCard = result.document_type?.disclose?.result !== 'passport';

    await mintNFT(verifierParams, isIDCard);
  });

  onError((err) => console.error('ZKPassport error:', err));

  // Open the ZKPassport QR/deep-link for the user
  window.open(url);
}
```

### Step 3 — Mint

```typescript
import { useWriteContract } from 'wagmi';

function useMintZKPassport() {
  const { writeContractAsync } = useWriteContract();
  const { chainId }            = useChainId();
  const network                = chainIdToNetwork(chainId);
  const nftAddress             = getAddresses(network).addresses.ZKPassportNFT;

  async function mintNFT(verifierParams: any, isIDCard: boolean) {
    const hash = await writeContractAsync({
      address:      nftAddress,
      abi:          ZKPassportNFT_ABI,
      functionName: 'mint',
      args:         [verifierParams, isIDCard],
    });
    return hash;
  }

  return mintNFT;
}
```

const { data: tokenData } = useReadContract({

### Listen for NFTMinted

```typescript
import { useWatchContractEvent } from 'wagmi';

useWatchContractEvent({
  address:   nftAddress,
  abi:       ZKPassportNFT_ABI,
  eventName: 'NFTMinted',
  onLogs(logs) {
    logs.forEach((log) => {
      const { to, tokenId, uniqueIdentifier, isOver18, nationality } = log.args;
      console.log(`NFT #${tokenId} minted to ${to} — ${nationality}, 18+: ${isOver18}`);
    });
  },
});
```

### Error Handling

| Revert message | User-facing cause |
|---|---|
| `"proof verification failed"` | ZKPassport proof is invalid |
| `"identifier already used"` | Same passport already minted an NFT |
| `"address already has NFT"` | Wallet already holds one |
| `"invalid domain or scope"` | SDK `domain`/`scope` doesn't match the contract |
| `"sender address mismatch"` | Proof was generated for a different wallet |
| `"chain id mismatch"` | Proof was bound to a different chain |

## FaucetManager

The faucet requires a ZKPassportNFT to claim ETH. Check eligibility before showing the claim button.

```typescript

const { data: canClaim } = useReadContract({
  address:      faucetAddress,

  functionName: 'canClaim',

// Claim ETH

await writeContractAsync({
  address:      faucetAddress,

```

## Multi-Network Helper

```typescript
export const CHAIN_ID_TO_NETWORK: Record<number, string> = {
  1:     'ethereum',
  8453:  'base',
  130:   'unichain',
  10:    'optimism',
};

export function chainIdToNetwork(chainId: number): string {
  return CHAIN_ID_TO_NETWORK[chainId] ?? 'base';
}
```
